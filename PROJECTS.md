# Selected Projects

This page summarizes public-facing RANNTA systems and engineering work suitable for technical review, partnerships, and hiring conversations.

## RANNTA X-Chain

Independent Layer 1 blockchain infrastructure.

Highlights:

- Native asset: RNTX
- Chain ID: `13113` (`0x3339`)
- Ethereum-style JSON-RPC interface
- Public RPC and explorer
- Rust-based node and runtime work
- Public seed and full-node topology
- Cross-platform node packaging

Public interfaces:

- https://rannta.com
- https://rpc.rannta.com
- https://explorer.rannta.com

## RANNTA Core

Node operator software and desktop control surface for RANNTA X-Chain.

Engineering scope includes Windows desktop software, node process control, synchronization visibility, public seed connectivity, Windows x64 packaging, Windows ARM64 packaging work, Linux x86_64 builds, Linux ARM64 builds, architecture verification, and release hashing.

The production repository remains private while public release packaging and review are completed.
